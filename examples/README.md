# Example organizations

Ready-to-load `.orga.json` files. Open the app and use **Import** on the
welcome screen to load one.

| File | Description |
|---|---|
| `acme-engineering.orga.json` | A realistic Team-Topologies org (7 teams, relationships, people) — used for the screenshot in the main README. |
| `starter-team-topologies.orga.json` | A minimal starting point with one team. |

All files are validated against the schema by the test suite.
